# Age rating checklist (App Store Connect)

Suggested answers for AdPlay metadata:

| Questionnaire item | Answer |
|---|---|
| Cartoon or Fantasy Violence | None / Infrequent as applicable from ad creatives |
| Realistic Violence | None (ads may vary — enable Infrequent if partner inventory includes it) |
| Sexual Content | None |
| Profanity | None / Infrequent (ads) |
| Drugs / Alcohol / Tobacco | None / Infrequent (ads) |
| Simulated Gambling | **No** (progress bar is not a slot/casino game) |
| Contests | **Yes** if framing rewards as contest; otherwise No — prefer honest “rewards” framing |
| Unrestricted Web Access | No |
| Gambling and Contests | Not real-money casino |
| **Contains Advertising** | **Yes** when live ads enabled; Yes for mock TestFlight if ads UI shown |
| Age | **17+** recommended |

Play Store content rating: complete IARC questionnaire similarly; advertising + users can earn crypto.
